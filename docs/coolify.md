# Coolify

Voltar para o [README](../README.md).

O Coolify é instalado e preservado por este repositório. Ele gerencia a aplicação, PostgreSQL, Redis/Valkey, domínios, certificados e o lifecycle dos containers da aplicação.

SigNoz e o collector PostgreSQL não pertencem ao Coolify nem a este repositório; consulte [espresso-observability](https://github.com/evellyncosta/espresso-observability).
