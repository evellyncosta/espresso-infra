# Aplicação Espresso API

Voltar para o [README](../README.md).

A API vive em [espresso-api](https://github.com/evellyncosta/espresso-api). O Coolify é responsável por build, deploy, variáveis, domínio e serviços da aplicação; este repositório prepara sua base de runtime.

Telemetria e a configuração da plataforma de observabilidade são responsabilidade de [espresso-observability](https://github.com/evellyncosta/espresso-observability).
